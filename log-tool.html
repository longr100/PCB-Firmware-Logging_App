Scent Dispenser – Log Tool

Download and clear device log data via USB-C

Browser not supported This tool may only work on Chrome, Safari, or Edge. Firefox does not support the Web Serial API.
Instructions
1. Connect the dispenser to your computer with a USB-C cable.
2. Click Connect to Device and pick the correct port from the browser dialog.
3. Click Select Folder and navigate to the utility/logs folder so files save there automatically.
4. Click Download Log — a CSV is saved to the logs folder and a chart appears below.
5. Optionally click Clear Log Memory to erase the log from the device.

Note: May only work on Chrome, Safari, or Edge.
Connection
Not connected

Use the USB-C port on the dispenser — not the UPDI programmer connector.

Windows users: if you see "No compatible devices found," the FTDI USB driver may not be installed. Download and install the free FTDI VCP driver (requires administrator access), then unplug and re-plug the USB-C cable and try again.

Actions
Logs folder: Downloads folder (default)

Download Log saves a .csv file named after the device ID to the selected logs folder (or your Downloads folder if none is set). Each download is a full snapshot — append previous files manually if needed.
