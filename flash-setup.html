Firmware Flash App – Setup

One-time setup to install and launch the firmware flash utility.

Connecting the UPDI Programmer

Firmware flashing uses a UPDI Friend programmer connected to the 3-pin header on the PCB — not the USB-C port (that is only for log download).

WireConnects toNotes
RED3V3Power
WHITERESET / UPDIData line
BLACKGNDGround
Before connecting USB: double-check wiring order and confirm the switch on the UPDI Friend is in the 3V position (not 5V).
Launching the Flash App

Python 3 must be installed once. After that, double-clicking the launcher handles everything — it installs required packages and opens the app automatically.

Mac
Windows
  1. Install Python 3 from python.org/downloads if you haven't already. Run the installer and follow the prompts.
  2. Download the app files: go to github.com/longr100/PCB-Firmware-Logging_App (GitHub is a website for sharing software files). Click the green Code button, then Download ZIP. A file called PCB-Firmware-Logging_App-main.zip will download — unzip it anywhere on your computer.
  3. Open the utility folder inside the unzipped folder in Finder.
  4. First time only: right-click start_mac.command → Open → Open (this tells macOS to trust the file). After that, you can double-click it normally.
  5. A Terminal window opens, installs packages (takes ~30 seconds the first time), then the app launches automatically.
Next time: just double-click start_mac.command. Packages are already installed so it opens the app immediately.

Windows USB Drivers

Windows requires drivers to communicate with the USB devices. These are installed once and do not need to be reinstalled. Administrator access is required to install — if you don't have it, ask your IT department.

DriverUsed forDownload
CH340 UPDI programmer (firmware flash) wch-ic.com ↗
FTDI VCP USB-C log port (log download) ftdichip.com ↗
Not sure if drivers are installed? Double-click check_drivers_win.bat in the utility folder. It checks both drivers and prints download links for any that are missing — no administrator access needed to run the check.
What the Flash App Does
  • Flash Firmware — select a .hex file and a port, then click Flash. Any new .hex files placed in the utility folder appear automatically in the dropdown.
  • Set Device ID — assign a name (up to 16 characters) to a device. This name becomes the filename for downloaded log CSVs.
The UPDI programmer must be connected to the 3-pin header before selecting a port in the app.
